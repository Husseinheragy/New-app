# New-app — آلة حاسبة بسيطة

مشروع Python صغير لاختبار بيئة Codex Cloud، يدعم الجمع والطرح والضرب والقسمة.
يعتمد على مكتبة Python القياسية فقط، ولا يحتاج إلى تثبيت مكتبات خارجية أو مفاتيح API.

## المتطلبات

Python 3.10 أو أحدث.

## التشغيل

من مجلد المشروع نفّذ:

```bash
python calculator.py add 8 2
python calculator.py subtract 8 2
python calculator.py multiply 8 2
python calculator.py divide 8 2
```

النتائج بالترتيب: `10.0` و`6.0` و`16.0` و`4.0`.
تُقبل الأعداد السالبة والعشرية. تعرض القسمة على صفر والمدخلات غير الصالحة
رسالة خطأ وتنهي البرنامج برمز خروج `2`.

لعرض المساعدة:

```bash
python calculator.py --help
```

## الاختبارات

```bash
python -m unittest discover -v
```

تغطي الاختبارات العمليات الأربع والأعداد السالبة والعشرية والصفر،
بالإضافة إلى واجهة سطر الأوامر والقسمة على صفر والمدخلات غير الصالحة.

## الملفات

- `calculator.py`: دوال العمليات وواجهة سطر الأوامر.
- `tests/__init__.py`: يتيح اكتشاف الاختبارات.
- `tests/test_calculator.py`: اختبارات آلية باستخدام `unittest`.
- `.gitignore`: تجاهل ملفات Python المؤقتة.
