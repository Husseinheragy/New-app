# New-app — آلة حاسبة بسيطة

مشروع Python صغير لاختبار بيئة Codex Cloud، يدعم الجمع والطرح والضرب والقسمة.
يعتمد على مكتبة Python القياسية فقط، ولا يحتاج إلى تثبيت مكتبات خارجية أو مفاتيح API.

## المتطلبات

Python 3.10 أو أحدث.

## التشغيل

من مجلد المشروع نفّذ:

```bash
python calculator.py add 8 2
python calculator.py subtract 8 2
python calculator.py multiply 8 2
python calculator.py divide 8 2
```

النتائج بالترتيب: `10.0` و`6.0` و`16.0` و`4.0`.
تُقبل الأعداد السالبة والعشرية. تعرض القسمة على صفر والمدخلات غير الصالحة
رسالة خطأ وتنهي البرنامج برمز خروج `2`.

لعرض المساعدة:

```bash
python calculator.py --help
```

## سجل العمليات الاختياري

لتسجيل عملية ناجحة في ملف JSON Lines تحدده بنفسك:

```bash
python calculator.py add 8 2 --history-file /tmp/calculator-history.jsonl
python calculator.py divide 8 2 --history-file /tmp/calculator-history.jsonl
python calculator.py history --history-file /tmp/calculator-history.jsonl
```

يمكن وضع `--history-file PATH` قبل اسم العملية أيضًا. يتطلب الأمر `history`
هذا الخيار، ولا يقبل أعدادًا. يعرض سجلًا بصيغة JSON لكل سطر، بترتيب الإضافة.
يحتوي كل سجل على `operation` و`a` و`b` و`result` و`timestamp` بتوقيت UTC
وبصيغة ISO 8601. يبقى عرض نتيجة الحساب كما كان.

دون الخيار لا تُحفظ بيانات ولا يُنشأ ملف سجل. تُسجّل العمليات الناجحة فقط،
ويُنشأ الملف عند أول تسجيل، ويجب أن يكون المجلد الأب موجودًا.
الملف الفارغ يُعرض دون مخرجات، والملف المفقود أو التالف ينتج رسالة خطأ.
تُرفض القيم غير المحدودة وNaN والمفاتيح المكررة (حتى لو تساوت قيمها).
يقبل التوقيت الشكل `YYYY-MM-DDTHH:MM:SS` مع جزء كسري اختياري من 1 إلى 6
خانات، وينتهي بـ `Z` أو `+00:00` فقط. تبقى سجلات الإصدار السابق متوافقة.
تظهر أخطاء القراءة والكتابة بوضوح دون traceback، برمز خروج `2`؛
إذا فشل الحفظ لا تُطبع نتيجة نجاح. لا يصلح البرنامج السجلات التالفة تلقائيًا،
بل يرفض الإضافة إليها دون تغييرها. تُحفظ السجلات القديمة وترتيبها، ويُضاف
فاصل سطر عند الحاجة إذا كان السجل الأخير صالحًا ولا ينتهي بسطر جديد.

### ضمانات الحفظ وحدوده

تُكتب نسخة كاملة في ملف مؤقت داخل المجلد نفسه، وتُنفذ `flush` و`fsync` ثم
يُغلق المؤقت قبل الاستبدال الذري باستخدام `os.replace`. عند فشل الكتابة
أو الإغلاق أو الاستبدال قبل اكتماله يبقى الأصل مطابقًا؛ يُنظف المؤقت،
وتظهر رسالة خطأ واضحة إذا تعذر تنظيفه بسبب نظام الملفات.

المؤقت والملفات الجديدة خاصة بالمستخدم (`0600`). عند استبدال ملف موجود
تُحفظ صلاحيات مالكه ضمن `0600`، وتُزال صلاحيات المجموعة والآخرين احترازيًا؛
لا تُنسخ ACL أو خصائص الملف الإضافية. تُرفض الإضافة إلى الروابط الرمزية
وغير الملفات العادية والملفات المملوكة لمستخدم آخر. يجب أن يتيح المجلد
الأب إنشاء الملف المؤقت والاستبدال.

الذرية تمنع ظهور نسخة مكتوبة جزئيًا أثناء التشغيل الطبيعي على نظام الملفات
نفسه، لكنها لا تعني ضمان بقاء آخر تحديث بعد انقطاع الطاقة: لا يُنفذ `fsync`
للمجلد، وتعتمد الاستمرارية أيضًا على نظام الملفات والتخزين. لا يوجد قفل
للكتابة المتزامنة؛ قد تفقد إحدى عمليتين متزامنتين تحديث الأخرى. الحفظ يعيد
نسخ الملف كاملًا ويقرأه إلى الذاكرة، وهو مناسب لسجلات المشروع التجريبي الصغيرة.
احفظ سجلك خارج المستودع
كما في المثال لتجنب إضافته إلى Git بالخطأ.

## تشغيل الاختبارات

```bash
python -m unittest discover -v
```

تغطي الاختبارات العمليات الأربع والأعداد السالبة والعشرية والصفر،
بالإضافة إلى واجهة سطر الأوامر والقسمة على صفر والمدخلات غير الصالحة.

## الملفات

- `calculator.py`: دوال العمليات وواجهة سطر الأوامر.
- `history.py`: قراءة سجل JSON Lines والتحقق منه والإضافة إليه.
- `tests/__init__.py`: يتيح اكتشاف الاختبارات.
- `tests/test_calculator.py`: اختبارات آلية باستخدام `unittest`.
- `tests/test_history.py`: اختبارات السجل وواجهة الأوامر باستخدام ملفات مؤقتة.
- `tests/test_history_persistence.py`: اختبارات سلامة الاستبدال والأعطال والتحقق الصارم.
- `.gitignore`: تجاهل ملفات Python المؤقتة.
